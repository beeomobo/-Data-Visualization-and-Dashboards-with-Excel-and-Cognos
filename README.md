**Data Visualization and Dashboards with Excel & Cognos Analytics**

**Project Overview**

This project focuses on analyzing car dealership sales and service data using **Excel** and **IBM Cognos Analytics**. The goal was to create meaningful visualizations and interactive dashboards that help regional management monitor dealership performance, profitability, sales trends, and service-related insights.

The project demonstrates skills in:

* Data visualization
* Dashboard development
* KPI reporting
* Business insights analysis
* Excel charting
* IBM Cognos Analytics


**Business Scenario**

As a Regional Manager for a chain of car dealerships, the objective was to:

* Analyze car sales performance across dealerships
* Track profitability trends over time
* Compare dealer performance
* Monitor service department insights and recalls
* Build dashboards to support data-driven business decisions


**Excel Data Visualizations**

The following visualizations were created in Excel to analyze dealership sales and profit performance.

_KPI Visualizations_

1. Quantity Sold by Dealer ID

**Visualization Type:** Bar Chart | **Purpose:** Compare vehicle sales volume across dealerships.

2. Profit by Date and Model

**Visualization Type:** Line Chart | **Purpose:** Analyze profit trends over time by vehicle model.

3. Profit by Year and Dealer ID

**Visualization Type:** Column Chart | **Purpose:** Evaluate yearly dealership profitability.

4. Sum of Profits for Hudson Model Cars by Dealer ID

**Visualization Type:** Line Chart | **Purpose:** Identify top-performing dealers for Hudson model sales.

**Cognos Analytics Dashboards**
Interactive dashboards were created in IBM Cognos Analytics to provide deeper operational and sales insights.

**Sales Dashboard**
_KPIs Included_
* Total Profit
* Quantity Sold
* Quantity Sold by Model
* Average Quantity Sold

_Dashboard Purpose_
This dashboard helps stakeholders:
* Monitor overall dealership sales performance
* Identify top-selling vehicle models
* Track profitability trends
* Compare sales metrics efficiently


**Service Dashboard**
_KPIs Included_
* Number of recalls per car model
* Customer sentiment analysis
* Quantity of cars sold per month compared to profit
* Number of recalls by model and affected system

_Dashboard Purpose_
This dashboard helps stakeholders:
* Identify recurring vehicle issues
* Detect recall trends and outliers
* Understand customer feedback patterns
* Compare sales performance against service-related challenges
